# Teachable_Machines
# مشروع تصنيف الصور باستخدام الذكاء الاصطناعي

# AI Image Classification Using Teachable Machine

## وصف المشروع | Project Description

قمت بتطوير مشروع لتصنيف الصور باستخدام الذكاء الاصطناعي من خلال منصة Google Teachable Machine، حيث تم تدريب نموذج للتعرف على الصور وتصنيفها إلى فئتين: Picasso وDuck.

بعد تدريب النموذج وتصديره بصيغة TensorFlow\.js، قمت بإنشاء واجهة ويب باستخدام HTML وCSS وJavaScript وربطها بالنموذج، بحيث تتيح للمستخدم رفع صورة وتحليلها وعرض نتائج التصنيف مع النسب المئوية للتوقعات.

I developed an AI-powered image classification project using Google Teachable Machine. The model was trained to recognize and classify images into two categories: Picasso and Duck.

After exporting the trained model in TensorFlow\.js format, I created a web interface using HTML, CSS, and JavaScript and integrated it with the model. The interface allows users to upload images, analyze them, and display classification results with prediction confidence percentages.

## خطوات تنفيذ المشروع | Implementation Steps

### خطوات التنفيذ

1. إنشاء نموذج لتصنيف الصور باستخدام Google Teachable Machine.
2. تحديد فئتين للتصنيف: Picasso وDuck.
3. تدريب النموذج وتصدير ملفاته بصيغة TensorFlow\.js.
4. تصميم واجهة ويب باستخدام HTML وCSS.
5. ربط النموذج بواجهة المستخدم باستخدام JavaScript.
6. إضافة خاصية رفع الصور وتحليلها باستخدام النموذج.
7. عرض نتائج التصنيف والنسب المئوية للتوقعات لكل فئة.
8. إضافة رسائل توضح حالة تحميل النموذج ومعالجة الأخطاء المحتملة.

### Implementation Steps

1. Created an image classification model using Google Teachable Machine.
2. Defined two image classes: Picasso and Duck.
3. Trained the model and exported its files in TensorFlow\.js format.
4. Designed a web interface using HTML and CSS.
5. Integrated the trained model with the web interface using JavaScript.
6. Implemented an image upload and classification feature.
7. Displayed classification results and prediction confidence percentages for each class.
8. Added model loading status messages and error handling.

4. CSS
5. JavaScript

## نتيجة المشروع | Project Outcome

تطوير واجهة ويب لتصنيف الصور باستخدام الذكاء الاصطناعي، تتيح للمستخدم رفع الصور وتحليلها وعرض الفئة المتوقعة مع نسبة الثقة في التصنيف، مما يوضح كيفية دمج نماذج التعلم الآلي مع تطبيقات الويب.

Developed an AI-powered image classification web interface that allows users to upload images, analyze them, and view predicted categories with confidence scores, demonstrating how machine learning models can be integrated into web applications.
